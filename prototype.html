Model and numerical details

We observe z = θ* + ε in six coordinates, using fixed synthetic noise. The initial weights are λ = (1, 0.55, 0.25, 0.10, 0.04, 0.015).

Fixed scalesθ̂j(t) = (1 − exp(−λj t)) zj
Trainable scalesdθj/dt = √(λj² + 4θj²) (zj − θj)λj(t) = aj(t)² = (λj + √(λj² + 4θj²)) / 2

The adaptive model uses θj = ajβj, aj(0) = √λj and βj(0) = 0. The scalar equation follows from a² − β² = λ. Curves use fourth-order Runge–Kutta integration; MSE is evaluated against the known synthetic truth, not against the noisy observations.
